# Outlasting The Middleman (OTM E-Commerce)

[![Next.js](https://img.shields.io/badge/Next.js-14%2B-black?style=flat-square&logo=next.js)](https://nextjs.org/)

[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-3.4%2B-38B2AC?style=flat-square&logo=tailwind-css)](https://tailwindcss.com/)

A high-performance web application platform designed for the sale of medical equipment.

---

## 🚀 Key Features

* **Server-Side Rendering (SSR) & Dynamic Caching:** Built for high-speed page loads and optimal search engine indexation.
* **Responsive UI/UX:** Mobile-first, component-driven design tailored for business transactions.
* **Type-Safe Architecture:** Built with TypeScript to prevent runtime errors across application workflows.
* **Modern Web Stack:** Integrated with scalable routing and state management patterns.

---

## 🛠️ Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Package Manager:** [pnpm](https://pnpm.io/)
* **Version Control:** Git & GitHub

---

## ⚙️ Getting Started

Follow these instructions to set up and run the project locally.

### Prerequisites

Ensure you have the following installed on your machine:
* **Node.js:** v18.17.0 or higher
* **pnpm:** v8.0.0 or higher
